Stockfish engine credits

FreeChess bundles Stockfish 19 Lite, the lite single-threaded WebAssembly variant of Stockfish.js 19.0.1. The unmodified engine runs in a local browser worker. Your practice positions are processed on your device.

Stockfish.js is maintained by Nathan Rugg. Based on Stockfish by Tord Romstad, Marco Costalba, Joona Kiiski, Gary Linscott, and other contributors. Lite neural network by Chris Bao (sscg13).

Build this variant

Extract the source archive. Install and activate Emscripten 6.0.9, Node.js/npm, Python 3, make, and shasum or sha256sum. In the extracted source directory:

npm install --ignore-scripts
node build.js --single-threaded --lite --strict-em-check -f

The package pins Terser 5.51.2. The build validates and uses the included src/nn-61e7af4bb97d.nnue; no network download is needed for that input. Outputs are src/stockfish-19-lite-single.js and src/stockfish-19-lite-single.wasm. FreeChess applies no engine patches. The build recipe was inspected; these bundled files are the upstream release assets.
